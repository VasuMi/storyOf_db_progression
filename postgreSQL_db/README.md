##Expense Tracker — Python + PostgreSQL

A command-line Expense Tracker built using Python and PostgreSQL.
The project allows users to add, view, update, delete, and calculate expenses while storing all data permanently in a PostgreSQL relational database.
This project demonstrates how a Python application communicates with a real database using SQL and the Psycopg PostgreSQL driver.

----------------------
       User
        ↓
Python CLI Application
        ↓
    SQL Queries
        ↓
     PostgreSQL
        ↓
   expenses table
-----------------------
